Lazyskills is a TUI for discovering, understanding, installing, and managing AI coding skills for people who want a faster way to work with skills across projects without manually digging through folders, markdown files, and install commands.

## Why Lazyskills Exists

- Skills are useful only if you can find the right one, inspect it quickly, and install it safely.
- Lazyskills gives you one keyboard-driven place to browse available skills, read their contents, and manage them across local and project scopes.
- It keeps install and remove operations aligned with the existing `skills` CLI instead of inventing a separate workflow.

## How It Works

1. Browse skills from local, project, and remote sources.
2. Preview markdown and metadata before making changes.
3. Install or remove skills through the configured `skills` command.
4. Revisit frequently used skills through favorites and faster navigation.
