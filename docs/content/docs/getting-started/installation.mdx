## Requirements

- Use one of the supported package managers below.

## Install with npx

```bash
npx lazyskills
```

Use this when you want to try lazyskills without installing it globally.

## Install with Cargo

```bash
cargo install lazyskills
```

## Install with Homebrew

```bash
brew install alpha-innovation-labs/tap/lazyskills
```

## Install with Scoop

```bash
scoop bucket add alpha-innovation-labs https://github.com/Alpha-Innovation-Labs/scoop-bucket
scoop install lazyskills
```

## Verify

```bash
lazyskills --help
```
